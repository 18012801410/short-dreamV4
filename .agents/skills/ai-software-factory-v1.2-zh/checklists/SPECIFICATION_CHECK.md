# 规格一致性检查清单（Specification Consistency Checklist）

- [ ] 目标用户明确

- [ ] 功能需求带有验收标准

- [ ] 架构覆盖主要需求
- [ ] 领域模型覆盖重要业务概念
- [ ] 需要之处状态机已显式化
- [ ] 技术栈与基础设施已定义
- [ ] API/契约明确
- [ ] UI 流程能映射到用例
- [ ] 重要页面的布局骨架与断点已定义
- [ ] UI 工作的设计 Token 与组件清单已定义
- [ ] AI 职责与工具明确
- [ ] 人类审批点明确
- [ ] 外部提供方已隔离
- [ ] 开发任务覆盖已批准的范围
- [ ] 待定问题已记录
- [ ] 无重大矛盾
