# 稳定版出图工作流使用说明

`QWEN文生图（稳定版）_api.json`（本目录）是为"资产设定卡出图稳定性"制作的
ComfyUI 工作流（API 格式），与在用极速版的差异：

| 项 | 极速版（现用） | 稳定版（本文件） |
|---|---|---|
| 加速 LoRA | Lightning 4-step（strength 1.0） | 无（Qwen-Image 基础模型直连） |
| 采样 | 6 步 / cfg 1 | 20 步 / cfg 2.5（官方原生口径） |
| 负向提示词 | ConditioningZeroOut（无效） | 真实 CLIPTextEncode（节点 7，默认质量负向已内置） |
| 单张成本/耗时 | 低（约 21 币 / ~100s） | 约 2-4 倍 GPU 时间（以 RunningHub 实际计费为准） |
| 适用 | 快速抽奖、草稿迭代 | 设定卡定稿、场景卡（无人强制） |

## 启用步骤

1. 打开 RunningHub → 工作流 → 导入 ComfyUI 工作流（API JSON），
   选择本目录的 `QWEN文生图（稳定版）_api.json`，保存后复制新的工作流 ID。
2. `.env` 修改两行：
   ```
   RUNNINGHUB_WORKFLOW_IMAGE=<新的工作流ID>
   IMAGE_NEGATIVE_NODE=7
   ```
   （`IMAGE_NEGATIVE_NODE` 留空 = 不发送负向词，兼容极速版，不会报错。）
3. 重启 API 与 worker。

## 代码侧联动（已实现，无需额外配置）

- `generate_asset_image` 命令支持可选 `seed`：固定 seed + 同提示词 = 可复现，
  便于在一张好图基础上做提示词微调迭代；
- 负向词按资产类型自动组装（`textnorm.py`）：
  - 角色/道具：质量负向（模糊/畸形/水印等）；
  - 场景：质量负向 + 人形负向（people/silhouette/mannequin…）——
    稳定版负向通道真正生效，这是场景图"无人"的最强手段；
- 节点 5（seed）/ 6（提示词）/ 8（宽高）编号与极速版一致，适配器契约不变。

## 不变项

- 二阶段高清放大链（4x ClearReality → 0.5 缩回 → 分块 VAE 重编码 → 二次采样 denoise 0.3）
- 输出节点 18（SaveImage），产物口径与极速版一致


## v2 单段版（推荐，速度优化）

`QWEN文生图（稳定版v2单段）_api.json`：在稳定版基础上去掉整条 4K 高清修复链
（4x 放大 → 缩回 → 分块重编码 → 二次采样），单次 16 步采样直出 1920×1080。

- 耗时：约为 v1 稳定版（双段）的 1/3（实测以 RunningHub 计费为准）
- 质量：1920×1080 原生采样，设定卡用途下与双段版肉眼差异极小
- 节点 5（seed）/6（提示词）/7（负向）/8（宽高）编号不变，适配器契约不变
- 启用：同样导入 RunningHub 拿新 ID，`.env` 里 `RUNNINGHUB_WORKFLOW_IMAGE` 换新 ID、
  `IMAGE_NEGATIVE_NODE=7` 保持不变，重启 API 与 worker

两个版本可同时存在于 RunningHub：v1 当"精修档"、v2 当"快速档"，用 .env 切换。
