# QWEN 图生图（Edit 参考版）工作流使用说明

`QWEN图生图（Edit参考版单段）_api.json`（本目录）是为**段关键帧一致性**制作的
ComfyUI 工作流（API 格式）。与在用文生图工作流的差异：

| 项 | 文生图（v2 单段，现用） | Edit 参考版（本文件） |
|---|---|---|
| 模型 | `qwen_image_fp8_e4m3fn_scaled`（文生） | `qwen_image_edit_2509_fp8_e4m3fn`（指令编辑，2509 支持多参考图） |
| 参考图输入 | 无（纯文本） | 最多 3 张（节点 10/11/12）——角色卡/场景卡作身份参考 |
| 一致性来源 | 仅提示词文字锚（脸锁不住） | 参考图锁脸与服装 + 提示词锁构图 |
| CLIP / VAE | `qwen_2.5_vl_7b_fp8_scaled` / `qwen_image_vae` | **完全相同**（无需重复上传模型） |
| 采样 | 16 步 / cfg 2.5 | 20 步 / cfg 4（官方 2509 非加速口径；嫌贵可在 UI 调 16 步 / cfg 2.5） |
| 参考图预处理 | — | 每张过 `FluxKontextImageScale`（自动限尺寸，卡图 1920 长边无需手动缩） |
| 单张成本 | 约 21 币 | 预计 1.5-2.5 倍（以 RunningHub 实际计费为准） |
| 用途 | 资产设定卡 | **段关键帧**（开场锚点图）；也可手动当图生图用 |

## 用途说明（为什么做这个）

纯文生图的关键帧锁得住服装/发型/风格，锁不住脸（每次独立抽卡，五官随机），
会导致关键帧与资产卡"证据冲突"。本工作流把**该段在场角色的资产卡直接作为
参考图**喂给 Qwen-Image-Edit-2509，生成"同一张脸 + 新构图/新场景"的开场帧，
从根上解决关键帧换脸问题。

## 启用步骤

1. 打开 RunningHub → 工作流 → 导入 ComfyUI 工作流（API JSON），
   选择本目录的 `QWEN图生图（Edit参考版单段）_api.json`。
2. **检查模型节点**：若节点 1（UNETLoader）标红提示模型不存在，在模型下拉里
   搜索 `qwen_image_edit_2509`，选择平台提供的对应 fp8/e4m3fn 变体后保存
   （节点 2 CLIP / 节点 3 VAE 与文生图版共用，应直接可用）。
3. 保存并发布，复制新的工作流 ID。
4. `.env` 增加一行（其余两行保持不变）：
   ```
   RUNNINGHUB_WORKFLOW_IMAGE_EDIT=<新的工作流ID>
   ```
   （留空或不配 = 关键帧仍走文生图工作流，行为与现在完全一致。）
5. 重启 API 与 worker。

## 平台接线（代码已实现，导入后即生效）

配置 `RUNNINGHUB_WORKFLOW_IMAGE_EDIT` 后，**关键帧生成**（`generate_keyframes` /
`generate_frame_image`）自动切换到本工作流，平台对节点的填写：

| 节点 | 字段 | 平台写入内容 |
|---|---|---|
| 6 | `prompt` | 关键帧正向指令（`compile_keyframe_prompt` 编译：风格行 + 锚点描述 + 资产身份锁） |
| 7 | `prompt` | `KEYFRAME_NEGATIVE`（禁文字/水印/拼贴/换脸等） |
| 8 | `width`/`height` | 项目画幅换算像素（同资产卡口径） |
| 5 | `seed` | 可选固定 seed（重抽可复现） |
| 10 | `image` | 参考图 1：该段**第一位在场角色**的已批准主设定卡（无角色则场景卡） |
| 11 | `image` | 参考图 2：场景卡（无则复用参考图 1） |
| 12 | `image` | 参考图 3：第二位在场角色卡（无则复用参考图 1） |
| 18 | — | 产物（SaveImage），落地口径与现有关键帧一致 |

参考图通过 RunningHub 上传接口换 `fileName` 后填入（与视频工作流 refs 同一通道）；
不足 3 张时用第一张复用填充，避免空节点报错。

**范围**：只有关键帧生成走 Edit 工作流；资产设定卡仍走文生图工作流
（`RUNNINGHUB_WORKFLOW_IMAGE`），互不影响。

## 注意事项

- Qwen-Image-Edit 的特性是"参考图身份 > 指令"：想要改姿势/换场景，指令里写
  "keep the same face and outfit, …"；若发现服装被参考图钉死，在指令里显式写
  改动点（平台编译的提示词已按此口径组织）。
- 指令里出现具体文字内容（如手机屏上的字）仍可能被画进图里——关键帧锚点描述
  不含台词/屏幕文字（分镜 Agent 口径），存量分镜回退路径生成前建议先补锚点描述。
- 回滚：`.env` 清空 `RUNNINGHUB_WORKFLOW_IMAGE_EDIT` 并重启，即回到纯文生图关键帧。
