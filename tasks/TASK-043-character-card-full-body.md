# TASK-043：角色卡从「正面半身定妆像」改为「正面全身定妆照」

日期：2026-09-16
来源：用户指令「人物也应该改成正面全身照」（延续 TASK-042 场景卡改单幅广角）。

## 背景：这条早有 A/B 结论，只等拍板

PROJECT_STATE 2026-09-16 的 TASK-029/EP001 记录里已经跑过 A/B：**同一角色（陆峥）同 seed，
半身版 vs 全身版** —— 全身版裤子/外套下摆/鞋的证据完整、脸部仍清晰，半身版下半身无据可依，
当时的建议就是「默认模板改全身立绘，待用户拍板」。本次用户拍板，落地为默认口径。

## 改动

| 层 | 内容 |
|---|---|
| AssetAgent（`agents.py:run_assets`） | 角色卡规则改为**单幅正面平视全身定妆照**：站直、正对镜头、双臂自然垂放、头到脚完整入画（不裁头顶与鞋）、人物占满画面高度并居中；**服装从头到脚完整可见**（上衣/下装/鞋与配饰）；仍为「一图一人、只画人物本身、严禁拼贴/多视图/三视图/分格」；随身配饰（手表/挂坠/工牌）照常画在身上，与「不画道具」不冲突 |
| AssetAgent 兜底卡 | LLM 漏「主设定」时确定性补的那张卡同步改全身（`full-body portrait … head to toe completely in frame`） |
| 编译期消毒（`h3_compiler`） | `_CARD_POSE_HINT_RE` 增加全身取景词：`全身/立绘/full-body/full-length/head-to-toe`——与 TASK-042 场景取景词同理，取景属卡片本身，留在锚点会把剧情镜头锁成全身站姿；`sanitize_character_anchor` 确定性剥离 |
| 关键帧提示词（`compile_keyframe_prompt`） | 身份锁行补一句「（角色参考图只用于身份——脸部特征与服装；本帧的景别、姿势与构图按上面的画面描述来）」——全身卡作为 Edit 参考图时，防止参考图的全身站姿压过特写与动作要求（与 TASK-042 场景行同一机制，TASK-038 实测的同一风险） |
| 存量维护（`scripts/normalize_asset_cards.py`） | 角色卡模板同步为全身；`--scenes-only` 泛化为 `--kind=character,scene,prop`（旧写法保留）；**新增空 image_plan 兜底**——没有计划项的资产点「生成」时用的是裸锚点（不带动画幅与卡片取景），现按类型补一条当前卡模板（实测命中 1 个：雷震） |
| 前端（AssetsTab 说明文案） | 改为「角色卡=正面全身定妆照（站直对镜头、头到脚完整，服装从鞋到配饰都看得清）」 |

- **取舍**：全身卡的脸在参考图里占的像素更少，理论上脸的身份信号弱于半身卡；
  EP001 同 seed A/B 的结论是「脸部仍清晰」，但那是 9:16 竖版。16:9 横版项目的全身卡
  人脸占比会更低，若某个横版项目出现脸不稳，可考虑该项目单独用半身卡（页面可直接改
  提示词重抽，不影响全局口径）。
