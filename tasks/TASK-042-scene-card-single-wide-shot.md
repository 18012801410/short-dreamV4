# TASK-042：场景卡从「多视角拼贴」改为「单幅广角全貌」

日期：2026-09-16
来源：用户反馈「关键帧生成不好，感觉是资产图片生成不好的原因，场景不要用多视图了。
能不能用广角镜头那样能够覆盖场景的大部分区域」。

## 诊断（不花钱的取证）

抽查存量场景卡实物（`data/media/<pid>/assets/`）：

- 「末班车复仇」p-0a7e731af817 的 9:16 场景卡：竖排三个面板被画成**细条 + 大片黑边**
  （letterbox），三个面板都只拍到驾驶区一角，车厢/过道/路况几乎没有空间信息；
- 「超神奶爸」p-b2dec367f0c2 的婚宴大厅卡（16:9 项目）：三面板本身画得不错，但它是一张
  **设定表（sheet）**，不是一个空间。

这张卡在两条链路上都被当成"空间依据"使用：

1. **关键帧（QWEN Edit 图生图，`_segment_reference_cards` 传角色卡 + 场景卡）**：
   参考图是三个**互相矛盾的机位**（主视角 / 反打 / 侧视）。提示词里的
   `以 [imgN] 为准` 无法指向"哪一面板"，模型只能在三个几何之间摇摆；
   而关键帧负向词里恰好写着 `split screen, collage, multiple panels`
   ——**参考图与负向词自相打架**。
2. **H3 视频（场景卡作为 `<Picture N>` 参考）**：送进去的是一张拼贴表，
   而不是一个镜头。

用户提的"广角覆盖大部分区域"正好同时解决两端：给关键帧一个**唯一、可摆放人物的
相机几何**，也给视频一张单镜头的空间参考。

## 改动

| 层 | 内容 |
|---|---|
| AssetAgent（`agents.py:run_assets`） | 场景卡规则重写：`整张卡只有一幅画面（不是多视图卡、不是拼贴、不分格）`；广角/超广角（约 16-24mm）从看见全貌的机位拍摄（室内取角落或略高视线，街道取一端/对面临街），空间绝大部分一次性入画（四面墙、两端、主要地标同框，纵深层次清楚）；`禁止分格/拼贴/多面板/多机位/平面图/线稿`；`scene_layout` 变量（竖排/横排三面板）删除 |
| AssetAgent（anchor 卫生） | 场景锚点新增禁写「广角/超广角/机位/视角/构图/全景/多视角」等取景短语——取景属卡片本身，写进锚点会把后续每个镜头的景别锁成广角远景 |
| 编译期消毒（`h3_compiler`） | 新增 `_SCENE_FRAMING_HINT_RE`，`sanitize_scene_anchor` = 空镜状态消毒 + 取景词消毒（存量数据兜底，不改 DB） |
| 关键帧提示词（`compile_keyframe_prompt`） | 场景行改为：`background: <锚点>，以 [imgN]（场景名） 为准（该参考图是同一空间的广角全貌：地标位置、朝向与相互距离以它为准；本帧的景别与构图按上面的画面描述来）`——参考图只当空间依据，**不给"保持不变"锁**（TASK-037/038 教训） |
| 出图负向（`textnorm.IMAGE_NEGATIVE_SCENE`） | 稳定版工作流（cfg>1，`IMAGE_NEGATIVE_NODE=7`）负向加 `split screen, collage, multiple panels, panel grid, diptych, triptych, comic panels, storyboard sheet, contact sheet, letterbox bars, black bars`，确定性保证卡是单幅 |
| 存量维护（`scripts/normalize_asset_cards.py`） | 卡模板更新为新口径（角色分支顺带修正为**正面半身定妆像**——旧模板还在出四视图，与 TASK-030 后的默认不一致）；新增 `--scenes-only`（只动场景）与 `--prompts-only`（不删图）两个开关 |
| 前端（AssetsTab 说明文案） | 改为「角色卡=正面半身定妆像；场景卡=空镜单幅广角全貌（无人，一眼看尽整个空间的地标与布局）；道具卡=白底居中」 |
